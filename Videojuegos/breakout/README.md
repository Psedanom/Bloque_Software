# Juego Breakout
### Pablo Sedano

### Instrucciones:
- Para poder correr el juego es necesario utilizar ya sea el index o el HTML de Breakout dentro de la carpeta "html"

### Controles:
- Espacio: para empezar a mover la pelota, puedes moverte para acomodarla antes de tirar
- A y D: mueven al jugador

### Reglas
- El jugador deberá utilizar la pelota para romper los bloques de colores sin dejar caer la pelota, de lo contrario pierde una vida.
- El juego termina cuando todos los bloques sean eliminados o cuando el jugador no tenga más vida.

### Cambios al gameplay
- El jugador puede mover la pelota antes de sacarla.
- Los bloques especiales te dan una pelota adicional, la cual no puede romper otros bloques especiales si los toca.
- Solo pierdes vida si la pelota principal cae.
